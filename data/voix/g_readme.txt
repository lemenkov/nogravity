              
  Übersicht über Tastenfunktionen

Ansichten

F2   : Cockpit-Ansicht          F3   : Ansicht im Uhrzeigersinn drehen
F4   : Ansicht drehen           F5   : MiniCam (Rückansicht)
F6   : NAV-Punkt-Ansicht        F7   : Missile-Ansicht

Details

F9   : Himmel Ein/Wenig/Aus        F10  : Bewegungs-Blur Ein/Aus
F11  : Anti Alias Ein/Aus     F12  : Stereo 3D Ein/Aus

Steuerung

L oder EINGABE : Zielfixierung      Tab : AfterBurner 
Leertaste : Auswahl verwenden         - und = Auswahl ändern
A   : In nächsten NAV-Sektor gehen ( Q auf französ. Tastatur )
0 und . : Rollen
1,2,3,4,5,6 : Waffe auswählen
+ und - : Gaspedal
Rechte Umschalttaste oder linke Maustaste: Schneller 
Alt Gr  oder rechte Maustaste: Mit ausgew. Waffe feuern

Verschiedenes

F1  : Hilfe anzeigen 
PrtScrn : Eine .PCX 8bit oder TGA 16bit-Datei auf C:\RT zwischenspeichern
I   : Informationen Ein/Aus
Esc : Spielunterbrechung

  Waffenübersicht:

1  TwinLaser    : Schuß mit geringer Energie.
2  QuadLaser    : Schuß mit mittlerer Energie. Für Handgemenge.
3  OctoLaser    : Hochenergieschuß. Langsamer, aber enorm
schädlich
4  Freezer      : Friert jedes Objekt einige Sekunden lang ein
5  Missile      : Freund/Feind-Geschoß. Ziel muß fixiert werden
                    Ausgezeichnet für Handgemenge
6  Torpedo      : Super-Missile . Lange Fixierungszeit . Für
Handgemenge
                    nicht empfohlen, eher für große Feindbasis.

  Bonus-Übersicht :

Ammo         : Mehr Munition für Waffen.
Cell         : plus +25% Schild 
MegaCell     : Schild wiederherstellen
Stealth      : Unsichtbarkeit. Feind kann 20 Sekunden nicht
angreifen.
SystemShield : Unsichtbarkeit!
Mantelfunktion : Warp zum aktuellen Nav-Punkt.
BlackHole    : Alles rundherum zerstören.
